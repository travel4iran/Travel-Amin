# Travel Amin – موقع ثابت (Static) | سایت ثابت

سایت معرفی خدمات گردشگری و سفر درمانی در ایران برای مخاطبان عرب‌زبان؛ **بدون بک‌اند و بدون پایگاه داده**.
کاربر خدمات را می‌بیند و با یک کلیک (یا فرم کوتاه) وارد گفتگوی واتساپ می‌شود.

## ساختار پروژه

```
index.html            صفحه اصلی
404.html              صفحه خطا
assets/css/style.css  استایل‌ها
assets/js/config.js   ⭐ تنظیمات (شماره واتساپ، تلگرام، آدرس Worker نرخ ارز)
assets/js/main.js     منطق سایت (منو، فرم واتساپ، کارت‌ها، تم تیره)
assets/js/intro.js    صفحه‌ی لودینگ (پرواز + مهر پاسپورت)
assets/js/rates.js    نرخ ارز
assets/js/theme-init.js  اعمال تم قبل از رندر + تصمیم نمایش صفحه‌ی لودینگ (فقط یک‌بار در هر نشست)
assets/img/           تصاویر
worker/rates-worker.js  Cloudflare Worker برای خواندن نرخ از TGJU
_headers              هدرهای امنیتی و کش (Cloudflare Pages / Netlify؛ GitHub Pages نادیده می‌گیرد)
llms.txt / robots.txt / sitemap.xml   سئو و معرفی سایت به موتورهای جستجو و هوش مصنوعی
.github/workflows/    انتشار خودکار روی GitHub Pages
```

## تغییر تنظیمات

فقط فایل `assets/js/config.js` را ویرایش کنید:

- `whatsapp`: شماره‌ی واتساپ بدون `+` و صفر (مثال: `989395464608`)
- `telegram`: لینک کانال تلگرام
- `rates.proxy`: آدرس Worker شما

> شماره‌ی واتساپ و آدرس Worker **عمداً عمومی** هستند (روی سایت دیده می‌شوند). هیچ کلید، توکن یا رمزی در این پروژه وجود ندارد و نباید هم قرار داده شود.

## نسخه‌بندی فایل‌ها (کش)

فایل‌های JS و CSS نام ثابت دارند. بعد از هر تغییر در آن‌ها، مقدار `?v=...` را در `index.html` و `404.html` عوض کنید (مثلاً تاریخ روز)، وگرنه بازدیدکنندگان ممکن است نسخه‌ی قدیمی را ببینند.

## انتشار روی GitHub Pages

1. یک مخزن (Repository) بسازید و همه‌ی فایل‌ها را در شاخه‌ی `main` بگذارید.
2. در **Settings → Pages → Build and deployment → Source** گزینه‌ی **GitHub Actions** را انتخاب کنید.
3. با هر `push` سایت خودکار منتشر می‌شود (`.github/workflows/pages.yml`).
4. دامنه‌ی اختصاصی: در همان بخش Pages دامنه را وارد کنید و در DNS رکورد CNAME بسازید.

## انتشار روی Cloudflare Pages (پیشنهادی)

GitHub Pages **هدر امنیتی** پشتیبانی نمی‌کند، اما Cloudflare Pages فایل `_headers` را اجرا می‌کند
(CSP کامل، HSTS، جلوگیری از iframe و …).

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git
2. Build command را خالی بگذارید و Output directory = `/`
3. دامنه را وصل کنید (SSL خودکار است).

## نرخ ارز (Worker)

مرورگر مستقیم از TGJU نمی‌تواند بخواند (CORS)، پس `worker/rates-worker.js` را روی Cloudflare Workers قرار دهید.
`ALLOWED_ORIGINS` همان فایل فعلاً فقط `https://travel4iran.github.io` را دارد. وقتی دامنه‌ی اختصاصی وصل شد، آن را هم به لیست اضافه کنید و Worker را دوباره Deploy کنید.
اگر نام Worker را عوض کردید، آدرس جدید را در `config.js`، متای CSP در `index.html` و `404.html` و فایل `_headers` به‌روز کنید.

## امنیت

- **CSP سخت‌گیرانه:** فقط اسکریپت و استایل همین سایت اجرا می‌شود (بدون inline، بدون `unsafe-eval`)؛
  فقط به Worker نرخ ارز درخواست شبکه می‌رود.
- بدون کوکی، بدون ردیاب، بدون ارسال داده‌ی کاربر به سرور. اطلاعات فرم فقط برای ساخت لینک واتساپ در مرورگر استفاده می‌شود.
- متن‌های فرم پاک‌سازی و کوتاه می‌شوند (حذف نویسه‌های کنترلی و هدایت‌کننده‌ی متن).
- لینک‌های خارجی با `rel="noopener noreferrer"`.
- فونت از Google Fonts بارگذاری می‌شود؛ برای حریم خصوصی بیشتر می‌توانید فونت Tajawal را در `assets/` میزبانی کنید و CSP را به‌روز کنید.

### صفحه‌ی لودینگ

انیمیشن ورود (پرواز + مهر پاسپورت) فقط در اولین بازدید هر نشست، با دکمه‌ی «تخطي»، و حدود ۵ ثانیه نمایش داده می‌شود. اگر کاربر «کاهش حرکت» را در سیستم فعال کرده باشد، اصلاً نمایش داده نمی‌شود. مدت پرواز در `assets/js/intro.js` (متغیر `T`) قابل تغییر است.

### قبل از هر commit
هرگز این‌ها را commit نکنید: فایل `.env`، کلید API، توکن، رمز، اطلاعات پزشکی یا شخصی مشتریان.
